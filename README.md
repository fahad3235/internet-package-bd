# Internet Package BD

Compare mobile data packs and plan your monthly data use — an offline,
bilingual (English / Bangla) web app for Bangladesh. No account, no server,
no network requests: your packs live in your browser's localStorage.

## Problem

Mobile operators in Bangladesh change data-pack prices and offers often, and
the "cheapest" pack is hard to spot: a 40 GB pack can cost less per GB than a
small one, and a pack that looks cheap may expire in 7 days. This app lets
you enter the packs you actually see (in your operator's app or USSD menu),
ranks them by cost per GB, estimates how much data you really need each
month, and tracks the pack you are using right now.

## Features

1. **Compare packs** — rank saved packs cheapest-first by cost per GB, with
   cost per day, data per day, cheapest badge, and savings vs the most
   expensive pack. Filter by operator (Grameenphone, Robi, Banglalink,
   Teletalk, Other) and pack type (Regular, Social, Video, Night, Combo);
   pause packs to hide them from the comparison.
2. **Data planner** — enter daily hours of video / social / browsing / music
   and a video quality (Low / Standard / HD) to get an estimated monthly
   need in GB, a suggested pack size, and the saved packs that cover it.
3. **My Pack tracker** — pick a pack and a start date, log data used so far,
   and see days left, data left, daily data budget, and a usage progress bar.
   Statuses: Active, Ends today, Expired, Data finished.
4. **Package manager** — add / edit / pause / delete packs with per-field
   validation (data 0.1–1000 GB, validity 1–365 days, price 1–100,000 BDT).
   Ships empty; one tap loads 3 clearly labelled fictional example packs.
5. **Backup & erase** — JSON export / import with strict validation, and a
   typed-DELETE erase-all.
6. **Bilingual UI** — full English / Bangla toggle, persisted, with Bengali
   digits in Bangla mode. Responsive down to 390px.

## What it does NOT do

- It ships **no real operator prices**. Rates change constantly; you enter
  the packs you see. Check your operator's app or USSD menu before buying.
- Usage rates (GB per hour) are **estimates**, labelled as such in the app —
  actual use varies with video quality, app updates, and background data.
- It never measures your data use itself; "used so far" is entered by you.

## Stack

- Plain HTML + CSS + vanilla JavaScript, no build step, no dependencies.
- `js/core.js` — pure logic (ranking, estimates, date math, validation).
- `js/data.js`, `js/i18n.js` — generated by `gen.py` (ASCII-only output;
  Bengali stored as `\uXXXX` escapes).
- `js/app.js` — UI layer (localStorage persistence, rendering, events).

## Prerequisites

Any modern browser. For local development, any static file server or just
open `index.html` directly — the app makes zero network requests.

## Install & run

```bash
# clone and open
git clone https://github.com/fahad3235/internet-package-bd.git
cd internet-package-bd
# option A: open index.html in a browser
# option B: serve it
python3 -m http.server 8000
# then open http://localhost:8000
```

To regenerate the generated files after editing `gen.py`:

```bash
python3 gen.py
```

## Deployment

Static site — deploy the repo root anywhere (GitHub Pages, Netlify, any
static host). GitHub Pages: Settings → Pages → Deploy from branch `main`,
folder `/ (root)`.

## Limitations

- Data is stored only in the current browser (localStorage); clearing site
  data erases it. Use Export JSON for a backup.
- The planner's GB/hour rates are rough estimates, not measurements.
- No live operator data — prices must be entered by hand.
- Dates use the device's local timezone.

## Status
